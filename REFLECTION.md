# Week 1 reflection
 
1. What is the difference between building a UI imperatively (plain DOM code) and 
declaratively (React)?
 
 Imperative requires us to manually write every step to update the DOM code. Declarative programming lets us describe what the UI should look like and let React handle the other updates.

2. Why must a component name start with a capital letter?

React requires component names in order to start with a capital letter so it distinguish the custom components from the standard HTML elements.
 
3. What does a fragment <>...</> do, and why not just use a <div>?

Fragments group multiple elements together without adding any unnecessary wrapper tags to the HTML DOM that could mess up the layout.
 
4. Name one benefit of splitting the UI into small components.

the benefit of splitting the UI into small components allows you to easily reuse the pieces of the code across the entire coding in the application.
